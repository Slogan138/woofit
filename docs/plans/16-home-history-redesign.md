# 16 · 홈·기록 화면 재배치

> **개선** · 폰 · 새 기능 아님

## 무엇을 하나

홈(P1) · 세션 기록(P6) · 루틴 상세(P2)의 **배치**를 바꾼다.
[15 · 세션 실행 화면 재설계](15-session-runner-redesign.md)에 이어지는 작업이다.

## 왜 접근이 15 와 다른가

15 는 구조를 갈아엎었다. 헬스장·땀 손·팔 뻗은 거리라는 요구가 표준 리스트와 정면으로
맞지 않았기 때문이다. **이 화면들은 그렇지 않다.** 소파에서 두 손으로 훑어보는 화면이고,
애플의 grouped list 가 이미 그 용도로 만들어져 있다. 전부 카드로 바꾸면 예뻐지는 대신
한 화면에 들어오는 정보가 준다.

그래서 규칙을 좁게 잡았다. **화면이 답해야 할 질문 하나만 크게 만들고 나머지는 표준 그대로.**

| 화면 | 답해야 할 질문 | 무엇을 키웠나 |
| --- | --- | --- |
| P1 홈 | 오늘 뭘 하지 | 오늘 루틴 하나를 화면 위쪽 전체로 |
| P6 기록 | 그날 얼마나 해냈지 | 성공 세트 비율을 행에 |
| P2 루틴 상세 | 이거 시작할까 | 시작 버튼을 하단 고정 |

## 요구사항

새 요구사항을 만들지 않는다. PRD 갱신도 없다 — P1 의 역할에 이미 "세션 시작"이 있고,
P6 은 "전체 세션 열람"이다.

- F-2 — 오늘 요일에 배정된 루틴을 위에 둔다. 전 종목·전 세트를 볼 수 있다.
- F-6 · F-12 — 기록에서 마크다운 재복사와 삭제 경로가 유지된다.
- PRD §9 — Dynamic Type, 색만으로 상태를 구분하지 않음.

## 주의점

**스와이프가 사라진 자리를 확인한다.** 홈이 `List` 를 벗어나면서 `swipeActions` 를 쓸 수
없게 됐다. 네 경로(편집·마크다운·복제·삭제)를 컨텍스트 메뉴로 전부 옮겼는지 매번 확인한다.
하나 빠져도 화면은 멀쩡해 보이므로 조용히 지나간다.

**기록은 `List` 를 유지한다.** 타임라인 안(시안 B)이 더 보기 좋았지만 `swipeActions` 를
직접 다시 만들어야 했다. F-12 의 삭제 경로가 프레임워크 밖으로 나가면 확인 대화상자까지
손으로 붙여야 하므로 여기서는 표준을 택했다.

**통계로 번지지 않게 한다.** 기록 화면을 손대다 보면 이번 달 총 볼륨·연속 일수를 넣고
싶어지는데 전부 M3(F-10)이거나 v1 범위 밖이다. 성공 비율 바는 이미 행에 `10/11 세트` 로
적혀 있던 값을 그림으로 바꾼 것일 뿐, 새 지표가 아니다.

**오늘 루틴이 없는 날을 먼저 본다.** 히어로 구조는 오늘 배정된 루틴이 있을 때를 전제한다.
없는 날 화면 절반이 비지 않도록 전체 루틴 카드 목록으로 갈아타는 경로가 있어야 한다.
