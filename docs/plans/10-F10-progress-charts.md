# F-10 · 종목별 추이

> **M3** · 폰 · [PRD §4 F-10](../PRD.md#f-10--종목별-추이-폰-m3) · 결정 근거 [D6](../PRD.md#11-확정-사항)

> 이 문서는 **실제 데이터를 보고 다시 썼다**(2026-08-30). 이전 판은 개요였고,
> "착수 시점에 실제 데이터를 그려보고 정한다"고 남겨둔 질문들이 있었다.
> F-13 으로 5개월치가 들어왔으므로 아래는 그 답이다. **추측이 아니라 측정값이다.**

## 데이터가 말한 것

원본 일지 `2026-03-31 ~ 09-01` · 73세션 · 470행 · 41종목을 집계했다.

### ① 무게는 거의 변하지 않는다

| 종목 | 수행 | 고유 무게 | 최장 미갱신 |
| --- | --- | --- | --- |
| 암풀 다운 | 23회 | **1종** (25kg 고정) | 22회 연속 |
| 사이드 레터럴 레이즈 | 22회 | **1종** (5kg 고정) | 21회 연속 |
| 이너 타이 | 22회 | 2종 | 20회 연속 |
| 스컬크러셔 | 22회 | 3종 | 10회 연속 |
| 아웃 타이 | 22회 | 3종 | 10회 연속 |
| 덤벨 숄더 프레스 | 22회 | 4종 | 10회 연속 |

**최고 무게만 그리면 대부분 평평한 직선이 나온다.** 이전 판은 "세션별 최고 무게
그래프"를 첫 지표로 뒀는데, 그렸다면 5개월 내내 아무 일도 없는 그림이 됐을 것이다.

### ② 진전은 세트 수와 횟수에서 일어난다

```
암풀 다운        25kg 고정 · 3s/15r → 4s/15r → 4s/12r → 4s/15r → 3s/15r → 4s/15r
사이드 레터럴     5kg 고정 · 3s/15r → 4s/15r → 5s/12r
덤벨 숄더 프레스   5kg/3s/15r → 6kg/4s/10r → 7kg/4s/12r → 8kg/4s/10r
```

무게를 올린 종목도 있지만(숄더 프레스 5→8kg), **무게가 고정된 종목에서도 세트가
늘었다.** 무게 축 하나로는 이 진전이 보이지 않는다.

### ③ 볼륨이 그 진전을 담는다

`무게 × 세트 × 횟수` 로 초기 3회 평균과 최근 3회 평균을 비교했다.

| 종목 | 초기 | 최근 | |
| --- | --- | --- | --- |
| 덤벨 숄더 프레스 | 230 | 320 | **+39%** |
| 아웃 타이 | 2,313 | 3,150 | **+36%** |
| 사이드 레터럴 레이즈 | 275 | 300 | +9% |
| 암풀 다운 | 1,275 | 1,375 | +8% |
| 스컬크러셔 | 600 | 600 | **±0%** |

무게 축에서는 전부 "변화 없음"에 가까웠던 종목들이 볼륨에서는 갈린다.
스컬크러셔가 0% 인 것도 정보다 — 무게는 10→20kg 로 올랐지만 횟수를 20→10 으로
줄여 상쇄됐다. **볼륨이 첫 지표여야 한다.**

## 정한 것

이전 판이 "착수 시점에 답한다"고 남긴 질문들에 대한 답이다.

**주 지표는 볼륨.** 최고 무게는 같은 화면의 보조 축으로 둔다 — 볼륨이 늘 때
무게로 늘었는지 횟수로 늘었는지 구분해야 하기 때문이다.

**1RM 추정은 만들지 않는다.** Epley(`weight × (1 + reps / 30)`)는 10회 이하에서
쓰는 근사인데, 실제 데이터는 `3s/10r` 121건 · `3s/15r` 91건 · `3s/12r` 58건으로
**12~15회가 절반 이상**이다. 15회에 적용하면 1RM 이 실제보다 크게 부풀고, 종목마다
횟수가 달라 종목 간 비교도 성립하지 않는다. 이전 판의 작업 단위 2번을 **뺀다.**

**기간 단위는 세션별.** 종목당 22회 / 22주 ≈ 주 1회라 세션별이 곧 주별이다.
주·월 집계를 따로 만들 이유가 없다.

**정체는 볼륨으로 정의한다.** "N주간 최고 무게 미갱신"으로 두면 암풀 다운이
22회 연속 정체로 잡힌다 — 5개월 내내 빨간불이라 신호가 되지 않는다.
**최근 3회 볼륨 평균이 그 이전 3회 대비 늘지 않았으면 정체**로 본다.

**종목 선택은 최근 수행순.** 41종목이라 목록으로 충분하다. 부위별 묶음은 만들지 않는다.

**성공률은 그리지 않는다.** 343✅ / 76❌ / 숫자 26 / 빈칸 8 로 82% 인데, 목표를
달성 가능하게 잡으니 당연한 값이고 시간에 따라 의미 있게 움직이지 않는다.
숫자 한 줄로만 보여준다.

## 어시스트 종목 — 방향이 반대다

| 종목 | 행 |
| --- | --- |
| 어시스트 풀업 | 21 |
| 마무리 어시스트 친업 | 19 |
| 어시스트 딥스 | 9 |
| **합계** | **49 / 470** |

보조 중량은 **줄수록** 향상이다. 볼륨 공식을 그대로 적용하면 향상이 감소로 그려진다.

**이번 범위에서는 그래프를 그리지 않는다.** 종목 목록에는 두되 추이 화면에서
"보조 기구 종목은 추이를 그리지 않습니다"로 안내한다. 세 종목뿐이고, 방향을 뒤집는
처리를 지금 넣으면 나머지 38종목의 공식까지 조건부가 된다. 앱에서 새로 기록하는
데이터에는 "(보조)" 표시가 없어 **식별 자체가 아직 불가능하다** — 종목에 속성을
두는 일이 선행되어야 하고, 그건 F-1 을 건드리는 별도 작업이다.

## 테스트 계획

집계는 순수 함수라 전부 테스트된다.

| 테스트 | 검증하는 것 |
| --- | --- |
| 볼륨 = 무게 × 횟수의 세트 합 | 기본 계산 |
| 실패 세트는 `actualReps` 로 계산된다 | 목표가 아니라 수행값(PRD) |
| 건너뛴 세트는 볼륨에서 빠진다 | 제외 규칙 |
| 무게가 고정이어도 세트가 늘면 볼륨이 는다 | **이 계획의 근거 자체** |
| 무게가 올라도 횟수가 줄면 볼륨이 그대로일 수 있다 | 스컬크러셔 사례 |
| 공백이 다른 같은 종목이 한 계열로 묶인다 | `normalize` 연결(F-9) |
| 6회 미만이면 정체를 판정하지 않는다 | 경계 |
| 최근 3회가 직전 3회보다 크면 정체가 아니다 | 정체 정의 |
| 세션이 1건이어도 계열이 깨지지 않는다 | 경계 |
| 중단된 세션도 계열에 포함된다 | 기록된 세트는 유효하다 |

## 주의점

**차트를 예쁘게 만드는 데 시간을 쓰지 않는다.** 정체 구간이 보이면 목적을 달성한 것이다.

**볼륨은 수행값으로 계산한다.** 목표 무게·횟수가 아니라 실제로 든 값이다. 실패 세트에
`actualReps` 가 반드시 있다는 불변식(D1)이 여기서 값을 한다.

**이 문서의 숫자는 마이그레이션한 과거 데이터 기준이다.** 근사 변환이므로(D8) 볼륨도
근사다. 실패 세트의 실제 횟수를 복원하지 않았기 때문에 과거 구간 볼륨은 실제보다
약간 높게 잡힌다. 추이 판단에는 영향이 없지만, 절대값을 신뢰하지 않는다.
